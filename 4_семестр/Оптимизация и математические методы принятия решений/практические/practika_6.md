# Отчёт по практической работе 6 (вариант 7)

## Определение параметров систем массового обслуживания

**Вариант 7.** В бухгалтерии предприятия два кассира; каждый обслуживает в среднем 30 сотрудников в час. Поток сотрудников — простейший, интенсивность 40 человек в час. Очередь не ограничена, дисциплина не регламентирована. Время обслуживания подчинено экспоненциальному закону. Требуется: вычислить вероятностные характеристики СМО в стационарном режиме и оценить целесообразность приёма третьего кассира (с той же производительностью).

---

## 1. Постановка задачи

- **Тип СМО:** многоканальная с ожиданием и неограниченной очередью (формулы Эрланга (6.25)–(6.30) в методичке).
- **Исходные данные:**  
  - число каналов \(C = 2\) (затем \(C = 3\));  
  - интенсивность потока заявок \(\lambda = 40\) (1/ч);  
  - интенсивность обслуживания одного канала \(\mu = 30\) (1/ч);  
  - приведённая интенсивность \(\rho = \lambda/\mu = 40/30 = 4/3 \approx 1{,}333\).

Условие существования стационарного режима: \(\lambda/(\mu C) < 1\), т.е. \(\rho/C < 1\).  
При \(C = 2\): \(\rho/C = (4/3)/2 = 2/3 < 1\) — режим стационарный.  
При \(C = 3\): \(\rho/C = (4/3)/3 = 4/9 < 1\) — тоже стационарный.

---

## 2. Расчёт для системы с двумя кассирами (\(C = 2\))

Вероятности состояний (6.25)–(6.26):

\[
P_0 = \frac{1}{\sum_{n=0}^{C-1} \frac{\rho^n}{n!} + \frac{\rho^C}{C!\,(1 - \rho/C)}},
\quad
P_n = \frac{\rho^n}{n!}P_0 \ (n < C),\quad
P_n = \frac{\rho^n}{C!\,C^{n-C}}P_0 \ (n \ge C).
\]

Подстановка: \(\rho = 4/3\), \(C = 2\).

\[
\sum_{n=0}^{1} \frac{\rho^n}{n!} = 1 + \frac{4}{3} = \frac{7}{3},\qquad
\frac{\rho^2}{2!\,(1 - \rho/2)} = \frac{(16/9)/2}{1 - 2/3} = \frac{8/9}{1/3} = \frac{8}{3}.
\]

\[
P_0 = \frac{1}{7/3 + 8/3} = \frac{1}{5} = 0{,}2.
\]

\[
P_1 = \rho P_0 = \frac{4}{3}\cdot 0{,}2 \approx 0{,}267,\qquad
P_2 = \frac{\rho^2}{2}P_0 = \frac{8}{9}\cdot 0{,}2 \approx 0{,}178.
\]

Среднее число заявок в очереди (6.27), при \(n = C\): \(P_C = P_2\)

\[
L_q = \frac{C\rho}{(C-\rho)^2}\,P_C = \frac{2\cdot(4/3)}{(2 - 4/3)^2}\cdot 0{,}178
= \frac{8/3}{(2/3)^2}\cdot 0{,}178 \approx 1{,}07.
\]

Среднее число заявок в системе (6.28):

\[
L_S = L_q + \rho \approx 1{,}07 + 1{,}333 \approx 2{,}40.
\]

Среднее время ожидания в очереди (6.29) и в системе (6.30):

\[
W_q = \frac{L_q}{\lambda} = \frac{1{,}07}{40} \approx 0{,}0268\ \text{ч} \approx 1{,}6\ \text{мин},
\qquad
W_S = W_q + \frac{1}{\mu} \approx 0{,}0268 + 0{,}0333 \approx 0{,}06\ \text{ч} \approx 3{,}6\ \text{мин}.
\]

Вероятность простоя (оба кассира свободны): \(P_0 = 0{,}2\).

---

## 3. Расчёт для системы с тремя кассирами (\(C = 3\))

\(\rho = 4/3\) без изменений. Знаменатель для \(P_0\):

\[
\sum_{n=0}^{2} \frac{\rho^n}{n!} + \frac{\rho^3}{3!\,(1 - \rho/3)}
= 1 + \frac{4}{3} + \frac{(4/3)^2}{2} + \frac{(4/3)^3}{6\,(1 - 4/9)}
\approx 1 + 1{,}333 + 0{,}889 + \frac{2{,}37}{6\cdot 0{,}556} \approx 3{,}93.
\]

\[
P_0 \approx 0{,}255,\qquad
P_3 = \frac{\rho^3}{3!}P_0 \approx \frac{2{,}37}{6}\cdot 0{,}255 \approx 0{,}101.
\]

\[
L_q = \frac{3\cdot(4/3)}{(3 - 4/3)^2}\cdot P_3 \approx \frac{4}{(5/3)^2}\cdot 0{,}101 \approx 0{,}15.
\]

\[
L_S = L_q + \rho \approx 0{,}15 + 1{,}333 \approx 1{,}48,\qquad
W_q = \frac{L_q}{\lambda} \approx \frac{0{,}15}{40} \approx 0{,}00375\ \text{ч} \approx 0{,}23\ \text{мин},
\]

\[
W_S = W_q + \frac{1}{\mu} \approx 0{,}037\ \text{ч} \approx 2{,}2\ \text{мин}.
\]

Вероятность простоя (все три кассира свободны): \(P_0 \approx 0{,}255\).

---

## 4. Сравнение вариантов и целесообразность третьего кассира

| Показатель              | 2 кассира | 3 кассира |
|-------------------------|-----------|-----------|
| \(P_0\) (все свободны)   | 0,20      | 0,255     |
| \(L_q\) (средняя очередь)| ≈ 1,07    | ≈ 0,15    |
| \(L_S\) (в системе)      | ≈ 2,40    | ≈ 1,48    |
| \(W_q\) (ожидание)       | ≈ 1,6 мин | ≈ 0,23 мин|
| \(W_S\) (в кассе)        | ≈ 3,6 мин | ≈ 2,2 мин |

Выводы:
- При двух кассирах средняя очередь около 1 человека, среднее время ожидания в очереди ≈ 1,6 мин
- При трёх кассирах очередь и время ожидания уменьшаются; время в системе падает с ~3,6 до ~2,2 мин.
