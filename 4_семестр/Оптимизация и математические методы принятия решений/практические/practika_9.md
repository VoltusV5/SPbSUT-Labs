# Отчёт по практической работе 9 (вариант 7)

## Нахождение оптимальных решений в задачах нелинейного программирования (метод множителей Лагранжа и теорема Куна–Таккера)

**Вариант 7**:

\[
\begin{cases}
f(x) = x_1^2 + x_1 x_3 - 2x_2 + 4 \to \min, \\
5x_1 - x_2 + x_3 = 1, \\
2x_1 + x_2 \le 3, \\
x_1 \ge 0,\quad x_3 \ge 0.
\end{cases}
\]


---

## 1. Постановка в стандартном виде

Множество планов и запись в виде (9.1):
\[
Q = \{x \in \mathbb{R}^3 : x_1 \ge 0,\ x_3 \ge 0\},\quad
g_1(x) = 2x_1 + x_2 - 3 \le 0,\quad
h_1(x) = 5x_1 - x_2 + x_3 - 1 = 0.
\]

Целевая функция:
\[
f(x) = x_1^2 + x_1 x_3 - 2x_2 + 4 \to \min.
\]

Ограничения линейны по \(g_1, h_1\); \(f\) — квадратичная с матрицей Гессе
\[
H = \begin{pmatrix} 2 & 0 & 1 \\ 0 & 0 & 0 \\ 1 & 0 & 0 \end{pmatrix}.
\]
Главные миноры: 2, 0, 0 — матрица неотрицательно определена, значит \(f(x)\) — выпуклая функция. Ограничения задачи линейны, следовательно, исходная задача является задачей выпуклого программирования.

---

## 2. Функция Лагранжа и условия Куна–Таккера

\[
\mathcal{L}(x,\lambda,\mu) = f(x) + \lambda_1 h_1(x) + \lambda_2 g_1(x) + \mu_1(-x_1) + \mu_3(-x_3),
\]
где \(\lambda_2, \mu_1, \mu_3 \ge 0\) для неравенств.

Стационарность по \(x\):
\[
\frac{\partial \mathcal{L}}{\partial x_1} = 2x_1 + x_3 + 5\lambda_1 + 2\lambda_2 - \mu_1 = 0,\quad
\frac{\partial \mathcal{L}}{\partial x_2} = -2 - \lambda_1 + \lambda_2 = 0,\quad
\frac{\partial \mathcal{L}}{\partial x_3} = x_1 + \lambda_1 - \mu_3 = 0.
\]

Дополняющая нежёсткость: \(\lambda_2 g_1 = 0\), \(\mu_1 x_1 = 0\), \(\mu_3 x_3 = 0\).

Из равенства \(h_1 = 0\): \(x_2 = 5x_1 + x_3 - 1\). 
Подстановка в \(g_1 \le 0\) даёт \(7x_1 + x_3 \le 4\). 
Допустимое множество в \((x_1, x_3)\) после исключения \(x_2\):
\[
Q_{13} = \{(x_1,x_3) : x_1 \ge 0,\ x_3 \ge 0,\ 7x_1 + x_3 \le 4\}.
\]

Это выпуклый треугольник с вершинами (по попарным пересечениям границ):
\[
A = (0,0),\quad B = \left(\frac{4}{7},0\right),\quad C = (0,4).
\]
Соответствующие им трёхмерные точки \((x_1,x_2,x_3)\) с учётом равенства \(h_1(x)=0\):
\[
A' = (0,-1,0),\quad
B' = \left(\frac{4}{7},\frac{17}{7},0\right),\quad
C' = (0,3,4).
\]


---

## 3. Подбор активных ограничений и решение

**поиск стационарной точки внутри \(Q\).**  
Подставляем \(x_2 = 5x_1 + x_3 - 1\) в целевую функцию и ищем безусловный минимум по \((x_1,x_3)\).  
Градиент приводит к системе:
\[
2x_1 + x_3 = 10,\quad x_1 = 2 \Rightarrow x_3 = 6.
\]
\(7\cdot 2 + 6 = 20 > 4\), то есть точка лежит вне допустимой области \(Q_{13}\).  
Следовательно, стационарной точки функции Лагранжа внутри \(Q\) нет, минимум достигается на границе множества планов.


**Анализ границ множества Q**

| Случай | Фиксированные переменные | Условие из h₁=0              | g₁ ≤ 0 и x ≥ 0 выполнено? | Результат / Граница                          | 
|--------|---------------------------|------------------------------|----------------------------|----------------------------------------------|
| 1      | x₁=0, x₂=0, x₃=0         | 0 = 1                        | —                          | Противоречие                                 | 
| 2      | x₁=0, x₂=0               | x₃ = 1                       | Да                         | Точка (0,0,1)                                | 
| 3      | x₁=0, x₃=0               | x₂ = -1                      | x₂ < 0                     | Точка (0,-1,0)                               | 
| 4      | x₂=0, x₃=0               | x₁ = 1/5                     | Да                         | Точка (1/5, 0, 0)                            |
| 5      | x₃=0                     | x₂ = 5x₁ - 1                 | x₁ ≤ 4/7                   | Отрезок A'B' (x₃=0, 0 ≤ x₁ ≤ 4/7)           | 
| 6      | x₁=0                     | x₂ = x₃ - 1                  | x₃ ≤ 4                     | Отрезок от (0,-1,0) до (0,3,4)               | 
| 7      | x₂=0                     | x₃ = 1 - 5x₁                 | x₁ ≤ 1/5                   | Отрезок от (1/5,0,0) до (0,0,1) (x₂=0)       | 

**Итог:**  
Граница состоит из **трёх рёбер** треугольника A'B'C':
- A'B' — x₃ = 0  
- A'C' — x₁ = 0  
- B'C' — x₂ = 0


**Явная проверка вершин.**

Рассмотрим вершины допустимого множества:
\[
A' = (0,-1,0),\quad
B' = \left(\frac{4}{7},\frac{17}{7},0\right),\quad
C' = (0,3,4).
\]
Значения целевой функции в этих точках:
\[
f(A') = f(0,-1,0) = 0 + 0 - 2(-1) + 4 = 6,
\]
\[
f(B') = f\left(\frac{4}{7},\frac{17}{7},0\right) = \left(\frac{4}{7}\right)^2 - 2\cdot \frac{17}{7} + 4 = \frac{16}{49} - \frac{34}{7} + 4 = -\frac{26}{49},
\]
\[
f(C') = f(0,3,4) = -2.
\]
Сравнивая, получаем:
\[
f(A') = 6,\quad f(B') \approx -0{,}53,\quad f(C') = -2.
\]


Так как задача выпуклая, глобальный минимум достигается либо в единственной внутренней стационарной точке, либо на границе и, в частности, на участках, где выполняются условия Куна–Таккера. Ниже проверим точку \(C' = (0,3,4)\) как решение системы ККТ.

Проверка границы \(x_1 = 0\): тогда \(x_2 = x_3 - 1\), \(x_3 \le 4\). При \(x_3 = 4\): \(x_2 = 3\), \(g_1 = 0 + 3 - 3 = 0\) — оба ограничения выполняются. Точка \(x = (0, 3, 4)\).

На этой точке: \(x_1 = 0\) (активно \(x_1 \ge 0\)), \(g_1 = 0\) (активно), \(x_3 > 0\) (неактивно), поэтому \(\mu_3 = 0\). Из условий ККТ:
- \(\frac{\partial \mathcal{L}}{\partial x_2} = 0 \Rightarrow \lambda_2 = 2 + \lambda_1\).
- \(\frac{\partial \mathcal{L}}{\partial x_3} = 0 \Rightarrow x_1 + \lambda_1 = 0 \Rightarrow \lambda_1 = 0\), значит \(\lambda_2 = 2\).
- \(\frac{\partial \mathcal{L}}{\partial x_1} = 0 \Rightarrow 0 + 4 + 0 + 2\lambda_2 - \mu_1 = 0 \Rightarrow 4 + 4 - \mu_1 = 0 \Rightarrow \mu_1 = 8\).

Все множители неотрицательны: \(\lambda_2 = 2\), \(\mu_1 = 8\), \(\mu_3 = 0\). Условия Куна–Таккера выполняются.

**Связь с теоремой Куна–Таккера.**  
Так как целевая функция выпукла, а ограничения линейны, то по теореме Куна–Таккера для выпуклых задач выполнение условий ККТ в точке \((x^*, \lambda^*, \mu^*)\) является не только необходимым, но и достаточным условием глобального минимума.  
Поскольку найденные множители \(\lambda_1, \lambda_2, \mu_1, \mu_3\) удовлетворяют условиям ККТ, точка \(x^* = (0,3,4)\) является глобальным минимумом исходной задачи.

## 4. Значение целевой функции

\[
f(0, 3, 4) = 0 + 0 - 6 + 4 = -2.
\]

Проверка ограничений: \(5\cdot 0 - 3 + 4 = 1\), \(2\cdot 0 + 3 = 3 \le 3\), \(x_1 = 0 \ge 0\), \(x_3 = 4 \ge 0\).

---

## 5. Ответ и выводы

**Оптимальное решение:** \(x^* = (0,\ 3,\ 4)\), **\(f(x^*) = -2\)**.

Множители Лагранжа/Куна–Таккера: \(\lambda_1 = 0\), \(\lambda_2 = 2\), \(\mu_1 = 8\), \(\mu_3 = 0\). Минимум достигается на границе по \(x_1\) и по ограничению \(2x_1 + x_2 \le 3\); переменная \(x_3\) в допустимой области положительна.
